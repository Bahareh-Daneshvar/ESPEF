# Dataset files

Full data is stored as separate yearly Parquets at the paths documented in the root README. Only 2021 is complete. Full Parquets and checkpoint archives are distributed separately to the project owner; a public research archive has not been selected.

The master manifest retains their SHA-256 checksums and actual byte sizes. The compact annual audit points to the complete compressed JSON audit and exclusion list. Gzip files are reports, not full raw corpora.

The 100-row CSV demonstrates the 2021 processed schema with 25 rows per quarter; it is not intended as a representative sample for analysis. The stage1 folder records the preceding aggregate audit across the entire approved date range; abstract-present candidate counts are not final usable counts.

The 2026 completeness check is still pending Stage 1B. Original OpenAlex publication dates are preserved, including dates flagged for unverified precision.
